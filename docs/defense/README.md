[Большой конспект всей защиты](../defense-guide.md) включает Docker, базу, CRUD, поиск, валидацию, статистику и экспорт. Эти четыре файла подробно разбирают **первый участок**: от команды Maven до появления главного окна.

Короткая схема для памяти:

```text
mvn javafx:run
  → pom.xml выбирает FxApplication
  → Application.launch вызывает start(Stage)
  → AppContext собирает сервисы
  → FXMLLoader читает main.fxml и создаёт контроллеры
  → Scene получает корневой элемент
  → Stage получает Scene и показывает окно
```
