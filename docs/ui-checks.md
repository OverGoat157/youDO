# Проверка экрана пользователей

20.10.2026: JDK 21, Maven 3.9.9, JavaFX 21.0.8, виртуальный дисплей Xvfb.

Проверки выполняются на реальных `users.fxml`, `user-form.fxml` и `app.css`, с сервисами и in-memory репозиториями. Это не проверка подключения PostgreSQL или системного оформления окон конкретного компьютера.

| Сценарий | Результат |
|---|---|
| Пустая таблица, отсутствие выбранной строки | Изменение и удаление отключены, добавление доступно |
| Обновление списка и выбор пользователя | Данные появляются в таблице, действия становятся доступны |
| Открытие редактирования | Имя и email заполнены текущими значениями |
| Отмена после изменения поля | Форма закрывается, данные пользователя не изменяются |
| Сохранение с занятым email | Форма остаётся открытой, ошибка видна, введённые поля сохранены |
| Исправление email и повторное сохранение | Пользователь создаётся, форма закрывается |
| Повторное заполнение контроллера | Флаг isSaved сбрасывается |
| Сохранение с задержкой | Поля и повторные действия отключены; закрытие крестиком блокируется |
| Завершение модального сохранения | Родительский список перечитывается |
| CSS обеих сцен | Загружается без ошибки FXML/CSS в тестах |

Найденное при ревью: крестик позволял закрыть форму во время записи; добавлен запрет закрытия на время сохранения. После обновления таблицы повторно применяется её сортировка.

Команда проверки:

```sh
xvfb-run -a mvn -Dyoudo.fx.tests=true clean package
```

На момент слияния пользователей: 94 теста прошли, 1 отдельный JDBC-тест выключен без настройки тестовой БД. Смена роли со связанными заказами и расширенная сервисная валидация проверяются в следующем PR сервисов. Проверки удаления с подтверждением и отказа БД дополняются при общей интеграции.
