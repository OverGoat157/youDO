## Исправления при интеграции

1. Форма заказа позволяла закрытие и отмену во время записи. Теперь блокируются закрытие, повторное сохранение и изменения полей; после успешной записи перечитывается родительский экран.
2. После ошибки загрузки пользователей форму заказа приходилось закрывать. Добавлено обновление списка без потери ввода.
3. Невозможная дата могла автоматически нормализоваться, например конец февраля. Парсинг теперь строгий и оставляет объяснение в форме.
4. Действия и экспорт были доступны во время загрузки заказов. Теперь они блокируются до получения актуального результата. Ошибка устаревшего запроса не заменяет состояние нового поиска.
5. Средний бюджет считался через double и мог потерять половину копейки при округлении. Теперь сумма и деление выполняются в BigDecimal; случай 0.01 и 0.06 даёт 0.04.
6. Панели действий и фильтров переносятся при сужении окна. Проверена фактическая ширина окна 820 px, действия остаются доступны.
7. README всё ещё описывал Java 17 и `java -jar` консольной КР №1. Обновлены требования, команды, пять участников, сценарий показа и статус Docker-примера.
